# Security policy

Please report vulnerabilities privately to **security@atcreations.ca** (or via GitHub's "Report a vulnerability" on this repository). Do not open public issues for security problems.

Include the affected component (api, storefront, admin, deploy), steps to reproduce and impact. We aim to acknowledge reports within 3 business days.

The security model and hardening decisions are documented in [docs/SECURITY.md](docs/SECURITY.md).
